# Roadmap — Walk, Log

## Phase 1 — MVP
- Walk (home): weekly quote, all walks, simple edit, simple delete.
- Log form: where (+ named place, city), when (date + time of day), how long, who.
- Stats dashboard.
- Coding: local storage (no auth), CSV export/import, a `/test` page preloaded with sample data.

## Phase 2 — Accounts & sync
- Telegram / Apple ID auth.
- Sync authenticated data to a server so it persists across devices.

## Phase 3 — Depth & control
- Quote archive (all quotes).
- Walk archive.
- Walk card removal with undo.
- Settings: default city, dark theme switcher, account deletion.

## Phase 4 — Richness
- Photo upload (up to 2 per walk).
- Walk View (detailed single-walk screen).
- Progressive stats disclosure ("Log 3 more walks to reveal your Environmental Landscape").
- Monthly tabs for All Walks.
